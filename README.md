# Guida John the Ripper

## Cosa è John the Ripper?
John the Ripper è un programma per il cracking delle password. 
Utilizza tecniche avanzate per decifrare password sicure e cifrati.

## Come Usare John the Ripper
1. **Scarica e installa** John the Ripper. Puoi farlo dal [sito ufficiale](https://www.openwall.com/john/).

### Passaggi:
1. Scarica John the Ripper dal sito ufficiale.
2. Estrai il file ZIP in una cartella a tua scelta (es. `C:\JohnTheRipper`).
3. Aggiungi John alla variabile di ambiente (opzionale, ma consigliato).
4. Crea un file con gli hash da craccare (vedi esempio `hash.txt`).
5. Usa il comando `john` per iniziare il cracking.
